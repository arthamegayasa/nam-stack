# Profile: general

For anything the other profiles do not fit.

- Derive the roles, evidence, rubric, invariants, and change budget from the goal, and write them into the charter so the user approves each one explicitly.
- Prefer evidence that can be observed or checked over opinion. Where none exists, say so in the charter; the gate then weighs proposals on reasoning alone, and the user knows it.
- **Versioning**: a commit per round inside a repo; otherwise `<name>.r<n>.<ext>`.
